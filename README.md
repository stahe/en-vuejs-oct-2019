[Vue.js] is a JavaScript framework. We introduced the JavaScript language in the previous document: [Introduction to ECMAScript 6](https://stahe.github.io/en-ecmascript6-oct-2019/).

We will not conduct an exhaustive study of the [Vue.js] framework. We will simply present the concepts that will be used later in writing a [Vue.js] client for the JSON version of version 14 of the tax calculation server (see [PHP 7 Tutorials and Courses](https://stahe.github.io/en-ecmascript6-oct-2019/)).

## Methodology

The scripts in this document are commented, and their console output is reproduced. Additional explanations are provided where necessary.

This document requires active reading: to understand a script, you must read its code, comments, and execution results.
